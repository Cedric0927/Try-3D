# Third-party code and attribution

This repository contains the MIT-licensed Anatomy project by Ryan:

- Upstream: https://github.com/wheresryan22/anatomy
- Full source snapshot: `reference/anatomy-main/`
- Selected drawing and verification tools: `vendor/anatomy/`
- License copies: `reference/anatomy-main/LICENSE` and `vendor/anatomy/LICENSE`

The Raptor engine geometry, animation and shaders are the official Anatomy example. This project adds Chinese navigation and component names. It does not claim the Raptor example as original work.

The conveyor and lift-transfer sorter have separately written application interfaces and logistics models. The sorter machine geometry is independently designed using Anatomy primitives and verification tools.
